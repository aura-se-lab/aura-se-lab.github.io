# Design variants (not published)

Fifteen homepage/research explorations plus one standalone mockup, kept for
reference. They used to live in `src/pages/research/` and `public/`, which
meant Astro built them as real routes: `/research/v1/` … `/research/v15/` and
`/v2.html` were reachable on auralab.sh and listed in the sitemap.

They are out of the build now. To look at one again, copy it back into
`src/pages/research/` and run `npm run dev`.

`v2-standalone.html` is self-contained — open the file directly.
