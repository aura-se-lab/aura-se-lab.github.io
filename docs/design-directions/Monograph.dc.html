Software written by machines should be cheap to run, plain to inspect, and honest about what it does not know.

The AURA Lab, founded in Fall 2024, advances research at the intersection of efficiency, automation, and explainability in software engineering. We shrink the foundation models that write code until they run inside a developer's own tools1; we pair them with program analysis so that their reasoning can be read, checked and corrected2; and we build the evaluations — human and automated — that tell a model that is right from one that is merely fluent3. Through rigorous methods, open collaboration, and a commitment to impactful work, the lab contributes practical advances in AI-supported software engineering for academia, industry, and society.

four lines of inquiry
I. Resource-efficient foundation models for code Quantization, parameter-efficient fine-tuning and distillation, measured on code quality as well as correctness.
II. Neurosymbolic reasoning and interpretability Neural models joined to grammars, types and analysis; explanations at the level developers think.
III. Reliability, causality and honest evaluation Counterfactual analysis and the study of automated judges — where they work, where they mislead.
IV. Agents across the software lifecycle Task-aware and multi-agent automation, from issue to review, measured end to end.
