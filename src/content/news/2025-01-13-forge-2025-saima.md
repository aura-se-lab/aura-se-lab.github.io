[Saima Afrin](/people/saima-afrin/) begins her Ph.D. with a publication in the [FORGE 2025](https://conf.researchr.org/home/forge-2025) Research Track: *Resource-Efficient & Effective Code Summarization*, with [Joseph Call](/people/joseph-call/), Khai-Nguyen Nguyen, Oscar Chaparro and Antonio Mastropaolo.

Code language models have become genuinely useful for bug fixing, code generation and documentation, and that usefulness has been bought by scaling — from millions of parameters to trillions. The bill arrives as compute, as latency and as carbon, and it arrives every time the model is adapted to a new task or a new codebase.

**QLoRA** — quantized low-rank adaptation — is one of the more promising ways out, because it fine-tunes a large model by updating a small set of adapter parameters instead of recalibrating all of them. Prior work had shown it works for tasks that go from natural language to code. Nobody had checked the other direction: summarization, where code goes in and prose comes out, and where the failure mode is a fluent description of the wrong thing.

The paper evaluates two state-of-the-art code language models across Python and Java. QLoRA does not merely make fine-tuning affordable for summarization — with minimal parameter adjustment it produces the **best** results in the comparison, ahead of full fine-tuning and the expensive recalibration that requires.
