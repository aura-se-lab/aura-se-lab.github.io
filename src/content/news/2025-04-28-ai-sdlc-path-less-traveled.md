*A Path Less Traveled: Reimagining Software Engineering Automation via a Neurosymbolic Paradigm*, with Denys Poshyvanyk, has been accepted at the [AI-SDLC 2025](https://conf.researchr.org/home/fse-2025/ai-sdlc-2025) workshop, co-located with the ACM International Conference on the Foundations of Software Engineering (FSE'25) in Trondheim, Norway.

Large code models have transformed how software engineering tasks get automated — generation, documentation, review, bug fixing — and the trade-offs have been accepted largely without argument. Performance has come at exponential computational cost, at the expense of interpretability, and through growing dependence on models with hundreds of billions of parameters and the data to match.

The paper argues for a different route. **Neurosymbolic Software Engineering (NSE)** pairs neural learning with symbolic, rule-based reasoning: the model supplies adaptability, the symbolic layer supplies something fast, deterministic and checkable. The point is not to replace the neural component but to give it a structure it can be held against, so that a claim about what a model did becomes verifiable rather than merely plausible.

It also proposes something less conventional — deliberately introducing a **controlled source of chaos**, to simulate the messy dynamics real software systems actually exhibit rather than the tidy ones benchmarks assume.

This is a position paper, and it names the direction the lab's interpretability work has been heading since.
